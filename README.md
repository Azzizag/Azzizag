## About me

I am an Informatics student at Telkom University (class of 2023) who works where testing meets AI. I spent my last internship automating tests for a payment system, and before that I led the AI side of a medical imaging app. I want to build software that is tested properly and AI that is useful in real workflows.

- QA Automation intern at **XLSMART** (Jun to Sep 2026): automated test flows with Katalon, documented API testing with Postman, tested the Payment Switch Board stream
- AI Engineer intern at **HUMIC Engineering, Telkom University** (Sep 2025 to Jan 2026): led the AI team for Lumira AI, built the breast cancer classification model and integrated it with the web team
- Mentor of the AI Engineer study group at **Big Data Laboratory**, where I teach AI agents
- Teaching and practicum assistant for Probability Theory, Computer Networks, and Algorithms & Programming

## Currently

- Final-year thesis on ECG arrhythmia classification with a hybrid CNN-Transformer model
- Running a self-hosted Hermes Agent on Telegram as my personal planning assistant
- Looking for **QA Automation** and **AI Engineer** roles and internships
